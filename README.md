# news_bot

sources.py: ваші RSS, публічні Telegram-канали та критерії для ШІ. Я одразу написав критерії під «Гаманець України» (курс, ставки, ціни, податки для ФОП), їх легко підкрутити.
fetchers.py: Листоноша, читає RSS і t.me/s/<канал>, віддає новини в єдиному форматі.
seen.py: Вахтер і Писар, зошит seen.json з уже обробленими новинами.
ai_filter.py: Розумник, питає Gemini і отримує {"publish": ..., "summary": ...}.
telegram_post.py: Голосник, публікує пост із джерелом.
main.py: з'єднує всіх по порядку.
requirements.txt: залежності.
